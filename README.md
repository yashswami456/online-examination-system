# Online Examination System 📝

A Java-based Online Examination System project with login authentication, MCQ exam, timer, auto submit, and result generation.

## Features
- User Login System
- Update Profile and Password
- Multiple Choice Questions (MCQ)
- Timer with Auto Submit
- Result Calculation
- Logout Functionality

## Technologies Used
- Java
- OOP Concepts
- IntelliJ IDEA

## Project Structure
- src/
- README.md
- run.bat
- run.sh

## How to Run
1. Open the project in IntelliJ IDEA
2. Run Main.java
3. Login and start the exam
